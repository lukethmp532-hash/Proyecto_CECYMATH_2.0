¿Qué es la Jerarquía de Operaciones?

Es el orden estricto en el que se deben realizar las operaciones matemáticas para garantizar que el resultado sea siempre el mismo. La regla se conoce comúnmente como PEMDAS.

  1. Paréntesis: ( ), [ ], { }
  2. Exponentes: x², √
  3. Multiplicación y División: (de izquierda a derecha)
  4. Adición (Suma) y Sustracción (Resta): (de izquierda a derecha)

Ejemplo: En la expresión 5 + 2 * 3, primero se hace 2 * 3 = 6, y luego 5 + 6 = 11.
