1. Fundamentos Teóricos

Explicación Conceptual

Una ecuación de segundo grado (o cuadrática) es una igualdad algebraica donde la incógnita aparece elevada, como máximo, a la potencia dos. Gráficamente, estas ecuaciones representan una parábola en el plano cartesiano.

Fig 1. Representación gráfica de una función cuadrática.

Definiciones y Fundamentos Matemáticos

La forma estándar de una ecuación cuadrática completa es:

ax² + bx + c = 0

  • Término Cuadrático (ax²): Determina la concavidad de la parábola. 'a' debe ser distinto de 0.
  • Término Lineal (bx): Influye en el desplazamiento horizontal.
  • Término Independiente (c): Indica el punto de corte con el eje Y.

Método de Solución: Fórmula General

Para encontrar las raíces (soluciones) de la ecuación, utilizamos la fórmula general:

El valor dentro de la raíz, b² - 4ac, se llama Discriminante (Δ):

  • Si Δ > 0: Existen dos soluciones reales y diferentes.
  • Si Δ = 0: Existe una única solución real (raíz doble).
  • Si Δ < 0: No hay solución real (soluciones complejas).

2. Ejemplos Resueltos

Ejemplo A: Dos soluciones reales

Resolver: x² - 5x + 6 = 0

  1. Identificamos coeficientes: a = 1, b = -5, c = 6.
  2. Sustituimos en la fórmula general:
    x = [ -(-5) ± √((-5)² - 4(1)(6)) ] / 2(1)
  3. Simplificamos:
    x = [ 5 ± √(25 - 24) ] / 2
    x = [ 5 ± √1 ] / 2
  4. Obtenemos las dos soluciones:
    x₁ = (5 + 1) / 2 = 3
    x₂ = (5 - 1) / 2 = 2

Ejemplo B: Solución única

Resolver: x² - 4x + 4 = 0

Calculamos el discriminante: b² - 4ac = (-4)² - 4(1)(4) = 16 - 16 = 0.

Como el discriminante es 0, la solución es x = -b / 2a = -(-4) / 2 = 2.
